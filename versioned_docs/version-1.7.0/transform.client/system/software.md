# Support & Software

Selecting the Support & Software tab, you'll find the **transform**.core and
**transform**.client version numbers of your system.

![The Current Software Versions](@site/static/img/transformclient/software-versions.png)

:::note

From **transform** version 1.7, we refer to the software that runs on
**transform**.engine and **transform**.go as **transform**.core.

:::

If a software upgrade is available for the connected **transform**.engine, it
will be shown here.

The **transform**.client software package very handily contains the matching
software for your **transform**.engine, so there's nothing else to download
when performing an upgrade.

We always recommend users upgrade to the latest available release. Engine
upgrades are backwards-compatible and we strive to ensure that audio processing
is identical between any two releases.

There are also links to this manual, the Fourier Audio support email address,
and an emergency help section if you ever run into trouble.

## Owner Registration

In this section, if the computer running **transform**.client is online, you
can see the registered owner of the connected transform hardware. If the hardware
is not registered, you can register it to receive exciting offers, discounts,
and future updates!

![A Registered Transform Engine](@site/static/img/transformclient/registered.png)

For any questions regarding owner registration, please contact us at support@fourieraudio.com.

## Log Files

At the bottom of the page, you'll find the log file download buttons.

Clicking 'Download transform.core logs' will warn you that you'll need to stop
the audio engine to download them; if happy to proceed, hit continue and you
will be will prompted to select a location to download to.

Selecting the client logs will open the relevant directory on your system,
making it easy to locate and copy the files that support may need.

:::note

Downloading logs can take 1-2 minutes.

:::

Logs are essential for our amazing support team to diagnose issues: it will
always be helpful if you could attach them if contacting us with a problem!
