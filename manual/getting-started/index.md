# Getting Started

So you've just got your hands on a **transform**.engine - congratulations!! Now, let's get you up and running.

## What will I need in order to get started with the **transform**.engine?

You will need:

- At least one **transform**.engine (:wink:).
- For **Dante**, one or more Dante-enabled devices and Dante Controller to configure audio subscriptions.
- For **HYPERPORT**, a [compatible DiGiCo console or interface](../connections/hyperport.md#compatibility), connected directly to the Primary port, plus a separate connection to the Control port.
- A computer to run the **transform**.client control software, running either Windows (10 upwards) or macOS (Intel and M1+). Once set up, your computer isn't required for running!

## Let's Roll

1. Is your transform.engine up to date? If yes, skip straight to number 2!

<a class="button button--lg button--primary" href="./engine-upgrade.md">Upgrade Instructions</a>  

2. Decide whether you want to connect to your **transform**.engine via Dante or HYPERPORT.

### HYPERPORT

Choose HYPERPORT for the lowest latency when connecting **transform**.engine
directly to a compatible DiGiCo console. Read the [HYPERPORT compatibility requirements](../connections/hyperport.md#compatibility)
before choosing HYPERPORT.

<a class="button button--lg button--primary" href="./hyperport-quickstart">Get started with HYPERPORT</a>  

### Dante

Dante lets you connect **transform**.engine to one or more other Dante enabled
devices across a standard network. Dante offers flexibility and cross-brand
compatibility but is slightly more complex to configure than HYPERPORT.

<a class="button button--lg button--primary" href="./dante-quickstart">Get started with Dante</a>
