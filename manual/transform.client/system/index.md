# System

The system section allows you to configure the system.

* [**Showfiles**](showfiles.md) - **transform**.engine automatically saves every change you make, immediately, but if you want to take your show file elsewhere, or copy it, you can do it here.
* [**Plugin Collections**](plugin-collections.md) - install, activate and deactivate **transform**.suite plugin collections.
* [**Patch Bay**](patch-bay.md) - view and edit the input and output routing for every chain in your showfile.
* [**MIDI IO**](midi-io.md) - configure global MIDI remote control and MIDI Tap Tempo.
* [**System Status**](system-status.md) - an overview of the different components of your system. Key detail here is ‘Audio IO’, this will tell you if the audio engine is ‘Running’ and a spinning cog for visual feedback!
* [**IP Configuration**](ip-configuration.md) - view and configure the network interfaces on your **transform**.engine.
* [**Performance**](performance.md) - a more detailed look at the DSP load.
* [**Support & Software**](software.md) - version numbers, log files and support information.
* [**System Reset**](reset.md) - restart the unit, delete all showfiles, or reset the plugin host to its factory settings. Proceed with caution when deleting showfiles or resetting the plugin host: these actions cannot be undone.
